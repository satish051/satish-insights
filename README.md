# Satish Insights

A modern, fast, and elegantly designed personal portfolio and blog. 
Built to showcase high-leverage ideas about technology, money, and life, and to display a collection of professional web projects.

## Features

- **Blazing Fast**: Built on top of Vite and React.
- **Glassmorphism UI**: Beautiful, premium aesthetic using modern CSS properties and blurred backdrops.
- **Fluid Animations**: Integrated with `framer-motion` for buttery smooth scroll-reveals and page transitions.
- **Fully Responsive**: A complete mobile-first approach including an animated hamburger menu, 1-column layouts, and fluid typography.
- **Dark Mode**: Integrated light/dark theme toggle for a tailored reading experience.
- **Custom Portfolio**: "My Works" section to elegantly display past projects (Kalika Business Advisors, RAC Kirtipur, Continuo).

## Getting Started

1. Clone the repository
2. Run \`npm install\` to install dependencies
3. Run \`npm run dev\` to start the local development server

## Deployment

This site is optimized for deployment on Vercel. 
Simply connect the GitHub repository to Vercel and it will automatically deploy the `main` branch.

**Note:** An `.npmrc` file is included in this repository with `ignore-scripts=false` to ensure `esbuild` permissions are handled correctly during the Vercel build phase.
