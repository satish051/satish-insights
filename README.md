# Satish Insights

A modern, fast, and elegantly designed personal portfolio, blog, and photography showcase. 
Built to share high-leverage ideas about technology, money, and life, and to display a collection of professional web projects and creative photography.

## Features

- **Blazing Fast**: Built on top of Vite and React.
- **Glassmorphism UI**: Beautiful, premium aesthetic using modern CSS properties and blurred backdrops.
- **Fluid Animations**: Integrated with `framer-motion` for buttery smooth scroll-reveals and page transitions.
- **Fully Responsive**: A complete mobile-first approach including an animated hamburger menu, 1-column layouts, and fluid typography.
- **Dark Mode**: Integrated light/dark theme toggle for a tailored reading experience.
- **Custom Portfolio ("My Works")**: Elegantly display past web development projects (Kalika Business Advisors, RAC Kirtipur, Continuo, Pixel Peak Media).
- **Photography Gallery**: A dedicated photography showcase to present visual art and captured moments.

## Getting Started

1. Clone the repository: `git clone https://github.com/satish051/satish-insights.git`
2. Install dependencies: `npm install`
3. Start the local development server: `npm run dev`

## Deployment

This site is optimized for deployment on platforms like Vercel or Netlify. 
Simply connect the GitHub repository to your preferred hosting provider, and it will automatically deploy the `main` branch.

**Note:** An `.npmrc` file is included in this repository with `ignore-scripts=false` to ensure `esbuild` permissions are handled correctly during the deployment build phase.

## Tech Stack
- React 18
- Vite
- Framer Motion
